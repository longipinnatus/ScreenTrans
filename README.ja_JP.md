## プロジェクトの特徴

* **マルチモデル対応**：軽量な PaddleOCR モデル（簡体字/繁体字中国語・英語・日本語）を内蔵し、カスタム PaddleOCR ONNX モデルの読み込みにも対応。高精度 OCR や特定言語への適応ニーズに対応できます（適応中）。
* **モデルパラメータの微調整**：OCR モデルのパラメータ調整機能を提供し、特定シーンでの認識率向上に役立ちます。
* **縦書きテキスト対応**：中日文の縦書きテキスト認識に対応し、漫画・小説・古典資料の読書シーンに適しています。
* **横画面/縦画面への適応**：端末の横向き・縦向き切り替え後も認識機能に影響しません。
---
* **標準 API 接続**：OpenAI 互換 API プロトコルとカスタム Endpoint に対応。
* **ストリーミング出力**：複数テキストボックス処理時に全体応答を待たずに表示でき、待ち時間を短縮します。
* **翻訳スタイルのカスタマイズ**：Prompt を編集でき、シーンに応じた翻訳スタイル調整や用語集の追加が可能です。
* **API 使用量統計**：トークン使用量の統計と課金見積もり機能を内蔵し、API コストをリアルタイムで把握できます。
---
* **結果フィルタのカスタマイズ**：テキストボックスのサイズや正規表現に基づき、無関係テキスト（ページ番号・透かし等）を自動で除外できます。
* **クリップボードへの自動コピー**：認識結果の自動コピーに対応し、コピー内容（原文のみ・訳文のみ・原文+訳文）を選択できます。
---
* **表示フォントのカスタマイズ**：システム内蔵フォントの選択、および外部 TTF/OTF フォントファイルの導入に対応。
* **UI 透明度調整**：オーバーレイテキストボックスとフローティングボタンの透明度を調整できます。
* **翻訳結果の自動非表示**：カウントダウン後の自動非表示に対応し、手動クローズモードも選択可能です。
* **自動カラー適応**：背景色を認識し、翻訳テキストボックスを元背景に自然に馴染ませます。

## 使用方法

デフォルトで DeepSeek API のパラメータが設定されています。設定で API キーを入力するだけで翻訳が可能です。

アプリはデフォルトで「領域選択モード」で動作し、フローティングボタン（懸浮球）で操作します：

* 領域選択（デフォルト設定）：
  * シングルタップ：自由選択を開始。画面上で任意の長方形領域をドラッグして指定すると、指を離した直後に認識・翻訳が行われます。
  * ダブルタップ：垂直範囲選択を開始。全幅を自動でカバーし、上下のスワイプで縦方向の範囲を確定します。長文の段落や会話の読解に適しています。
  * キャンセル：指定した領域が非常に小さい場合、操作はキャンセルされます。

* 全画面翻訳モード（設定で切り替え可能）：
  * シングルタップ：現在の画面全体のコンテンツを認識・翻訳します（多くのテキストが誤って統合されている場合は、「設定 -> OCR -> テキストボックスを統合」をオフにしてください）。

認識が開始されると、まず OCR の結果が表示されます。翻訳テキストが取得されると、翻訳結果がオーバーレイ層として元の文字位置に重なって表示されます。画面をタップすると閉じることができます。

画面オフや画面の回転が発生すると、画面録画権限の再申請が必要になる場合があります。ボタンを操作した際に権限が失効している場合は、現在の画面に許可申請のダイアログが表示されます。

## 必要な権限

必須の権限：

* 他のアプリの上に重ねて表示：翻訳をオーバーレイ表示するために必要です。
* 画面録画（メディア投影）：OCR 認識のために画面キャプチャを取得するのに使用します。

推奨される権限：

* 通知：有効にすると、バックグラウンドでの Toast 通知が安定します。
* クリップボードへの書き込み：一部のカスタム OS では「常に許可」に設定する必要があります。
* バックグラウンドからの画面表示：画面オフ後にシステムが録画権限を回収するため、有効にするとスムーズに再リクエストが可能になります。
