## プロジェクトの特徴

### 1. 高速で軽量な OCR 認識
---
* **マルチモデル対応**：軽量な OCR モデルを内蔵（簡体字/繁体字中国語、英語、日本語に対応）。カスタム ONNX モデルのロードもサポートしており、高精度な認識や特定の言語への適応が可能です。
* **モデルパラメータの微調整**：パラメータ調整パネルを提供。異なる解像度のソースファイルに合わせて認識パラメータを最適化し、特定のシーンでの認識率を向上させることができます。
* **縦書きテキストへの適応**：中日文の縦書きテキスト認識をサポート。漫画、小説、古文書などの閲覧シーンに適しています。
* **画面の向きへの適応**：デバイスの横向きと縦向きモードをシームレスに切り替えて使用できます。

### 2. 自由度の高い LLM 統合
---
* **標準 API 接続**：OpenAI API プロトコルをサポートし、カスタムエンドポイントに対応しています。
* **ストリーミング出力**：翻訳内容を順次返却。複数のテキストボックスを処理する際、全体の応答を待たずに表示を開始できるため、待ち時間を短縮できます。
* **カスタム翻訳スタイル**：ユーザー独自のプロンプト（Prompt）を設定可能。シーンに合わせて翻訳スタイルや用語を調整できます。
* **使用量の透明化**：トークン使用統計と課金計算機能を内蔵。リアルタイムで API の消費コストを把握できます。

### 3. 自動化プロセス
---
* **カスタム除外ロジック**：テキストボックスのサイズや正規表現に基づき、不要な領域を自動的に無視。ページ番号や透かしなどを効果的にフィルタリングします。
* **クリップボード同期**：認識結果の自動コピーをサポート。コピーする内容（原文のみ、訳文のみ、または原文と訳文の対照）を自由に設定できます。

### 4. パーソナライズ・カスタマイズ
---
* **フォントの自由度**：表示フォントのカスタマイズが可能。外部の TTF/OTF フォントファイルのインポートに対応しています。
* **UI 透明度の調整**：テキストボックスとフローティングボタンの透明度を個別に設定できます。
* **動的なインタラクション**：翻訳結果を一定時間後に自動で非表示にする機能や、手動で閉じるモードを切り替え可能。
* **カラーアダプティブ（色適応）**：背景色の上書きをサポート。翻訳テキストボックスの色を元の背景と自動的に融合させ、ネイティブに近い視覚効果を提供します。

## 使用方法

デフォルトで DeepSeek API のパラメータが設定されています。設定で API キーを入力するだけで翻訳が可能です。

アプリはデフォルトで「領域選択モード」で動作し、フローティングボタン（懸浮球）で操作します：

* 領域選択（デフォルト設定）：
  * シングルタップ：自由選択を開始。画面上で任意の長方形領域をドラッグして指定すると、指を離した直後に認識・翻訳が行われます。
  * ダブルタップ：垂直範囲選択を開始。全幅を自動でカバーし、上下のスワイプで縦方向の範囲を確定します。長文の段落や会話の読解に適しています。
  * キャンセル：指定した領域が非常に小さい場合、操作はキャンセルされます。

* 全画面翻訳モード（設定で切り替え可能）：
  * シングルタップ：現在の画面全体のコンテンツを認識・翻訳します（多くのテキストが誤って統合されている場合は、「設定 -> OCR -> テキストボックスを統合」をオフにしてください）。

認識が開始されると、まず OCR の結果が表示されます。翻訳テキストが取得されると、翻訳結果がオーバーレイ層として元の文字位置に重なって表示されます。画面をタップすると閉じることができます。

画面オフや画面の回転が発生すると、画面録画権限の再申請が必要になる場合があります。ボタンを操作した際に権限が失効している場合は、現在の画面に許可申請のダイアログが表示されます。

## 必要な権限

必須の権限：

* 他のアプリの上に重ねて表示：翻訳をオーバーレイ表示するために必要です。
* 画面録画（メディア投影）：OCR 認識のために画面キャプチャを取得するのに使用します。

推奨される権限：

* 通知：有効にすると、バックグラウンドでの Toast 通知が安定します。
* クリップボードへの書き込み：一部のカスタム OS では「常に許可」に設定する必要があります。
* バックグラウンドからの画面表示：画面オフ後にシステムが録画権限を回収するため、有効にするとスムーズに再リクエストが可能になります。
